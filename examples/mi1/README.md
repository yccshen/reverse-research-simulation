# MI-1 全流程（第三轮 · 图像密集型湿实验论文）

> 用同一套九阶段流水线跑一篇**完全不同的形态**：不是语言模型论文，是一篇 13 页、6 张主图、12 张补图的湿实验器件论文。这一轮的任务不是再验证一遍模板，而是回答一个问题：**为"纯文本 + 表格驱动"论文设计的流程，换到"图就是数据"的论文上要改哪几处。**

## 这一轮的三个结论

### 一、误差基线：总量降了，但 P0 的形态没动

| 指标 | GPT-1 首跑 | GPT-2 第二轮 | **MI-1 第三轮** |
|---|---|---|---|
| 带标签实质断言 | 约 60 条 | 约 55 条 | 约 58 条 |
| P0–P2 合计 | 17% | 18.2% | **12.1%** |
| 其中 P0 | 2 条（3.3%） | 1 条（1.8%） | **1 条（1.7%）** |
| P0 形态 | **缺席断言** | **缺席断言** | **缺席断言（第三次）** |

三条待生效条款（措辞强度 / 引用与动机两分 / 审计提示词固化）自本轮起生效。**效果是部分的**：

- ✅ "引用与动机两分"**起了作用**：S2 严格区分了"引文列表"与"引用功能位"，GPT-2 那条 P0（"改动没有任何引用"）没有复发；
- ✅ 总量从 18.2% 降到 **12.1%**；
- ❌ **P0 的形态没变**：本轮唯一那条 P0 仍是把"我的注意范围里没有"写成了"论文里没有"——而且同一个清单里还有**第二例**以 P2 出现的同形态错误；
- ❌ **措辞强度条款不会自我执行**：4 条 P2 里有一条正是它针对的病根，而它发生在该条款生效的同一轮。

→ **下一轮应把"缺席断言禁令"从"不得写论文未引用某文献"扩展到"任何以'从未／均未／没有'开头、关于论文内容的断言，必须先做全文检索并在句内注明检索词"。**

### 二、新增一条轨道：图轨（figure track）

前两轮把"图不可核验"记成物理限制（GPT-2 S8 原话：*Figure 1–5 全部无法从纯文本核验*）。**这一轮把它变成了一条通道。**

做法只有一句话：**真的去读图。** 具体是四步——抽内嵌栅格 + 整页渲染 → 逐面板裁剪（含纵轴标签带）→ 找框线 → 曲线数字化。标定优先找图内自带的标定点（本轮用"图注给 5 个时间戳 + 图里有 5 条竖虚线"反解出 18.5 像素/秒，自带残差检验，最大残差 0.6 秒）。

图轨在 6 张主图上产出 **8 条实质发现**，其中 5 条成了"论文自身问题"（对照物从图上消失、两个面板量纲不同、幅值系统性偏差 1.5–2.6 倍、单位写成 mV、疲劳指标基线反向偏移）。

**但本轮最出乎意料的一条是：图轨撤销了三次假发现，其中两次撤销的是隔离审计方提出的指控。**

| 被撤销的假发现 | 提出者 | 撤销依据 |
|---|---|---|
| 归一化预测力被 100% 上限截断 | 流程自产 | 其中一处峰值只有约 45–52%，饱和只发生在另一处单面板 |
| 致动段 EMG 幅度明显大于未致动段 | **隔离审稿人** | 逐列像素测幅：20.9 px 对 20.4 px，实质相同 |
| 图里的手势分类数与正文不符 | **审计子代理** | 图面逐行核对：4 个腕部手势 + 1 个手指手势 + 3 种抓取，与正文完全一致 |

→ **一条只会找茬的审计通道，会把"看起来不对劲"升级成指控。只有可量化的读数才能同时否决这些指控。隔离只保证视角独立，不保证结论可靠。**

### 三、第 0 步的框架要换掉

| | 语言模型论文 | 湿实验论文 |
|---|---|---|
| 框架 | "逐行算差值" | "逐图逐行重算 + 图注-正文-图面三方对齐" |
| 审计物 | 表格 | 图 |

本轮实测：**"逐行重算"框架的独有产出为 0（唯一一条被撤销），"读图"框架独占 5 类发现。** 三方（隔离审稿人 / 审计子代理 / 图轨）在 16 类发现上的交集只有 1 类，且两类都被三方共同漏掉。

**关键机制**：**图注是最接近图面的文本锚点**——正文可以隔着缺件引用，图注不能。三方不一致时先看图注站在哪边，能立刻分开"正文口径问题"与"图面／数据问题"。

## 已知局限（诚实声明）

- 样本量 **n=4**（一篇 GPT-1、一篇 GPT-2、一篇 MI-1，其中 MI-1 与 GPT-1 各含一个额外阶段实例），且形态只覆盖**两类**。湿实验内部的化学合成类、体内实验类、临床研究类都没有数据。
- 图轨全部读数由目视 + 自写脚本像素分割完成，**未使用任何曲线数字化专用库**；对坐标轴密集、曲线互相遮挡或低分辨率截图的情况没有可靠性数据。
- 这一轮的"每类结论"逐条核验只做到了图轨能覆盖的范围；**15 条不可核验清单所依赖的补充材料始终不在手上**，相关断言在本流程内**无法验证，也无法反驳**。
- 图轨能撤销假发现这一条，只证明了"它可以撤销"，没有证明"它能撤销足够多"——本轮撤销 3 条、发现 8 条，**这是单例，不是基线**。
