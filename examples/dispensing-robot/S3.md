# S3 · 建模迭代（变体 B：工序迭代）

**口径**：目标——还原方案从弱到强的迭代链，每一步的死因要经得起内行推敲；现状——S1/S1.5/S2 档案（四模块方向、三项 scope 已砍、无现成开启机构可抄）；限制——v0/v1 允许【合理重构】，但死因必须有据。**本阶段只有最后一段允许看论文，其余段落我按"当时的我"写。**

## v0：整机仿制路线（六轴臂 + 末端相机）

最直接的形式化：把 CytoCare 的架构抄过来——HEPA 洁净区 + 六自由度串联臂 + 臂末端工业相机 + 药具区，配药动作全部由机械臂完成【合理重构，依据：§1.3.1 对 CytoCare 架构的描述 + S1 的 naive 想法】。

它死在三件事上，而且一件事都躲不开：

1. **控制规模**。我们粗算过：抓取要竖直 + 水平 + 旋转 + 夹持，抽吸要旋转 + 拉压 + 两个夹持，消毒开启要转动 + 施力矩 + 刀轮，药品安置要转架——就算不上机械臂，光这四个模块就逼近两位数个关节；再叠六轴臂，总自由度会突破 15。以组里"一片六轴运动控制卡 + 一名硕士生写控制程序"的条件，这不是调参问题，是把项目周期整个押进去的问题【合理重构，依据：S1.5 的团队资源结构与四模块动作分解】。
2. **串联臂的奇异点与刚度**。配药动作全部是小行程、高定位精度（0.02mm 量级）的点位操作，串联臂在这个行程范围内没有优势，反而引入运动学奇异点和累计误差。
3. **仍然解决不了安瓿瓶**。六轴臂只是执行器，开启机构一个都没有，换了胳膊不等于有手。

**v0 死因（一句话）：执行器的自由度买不来我们缺的那个机构。**

## v1：笛卡尔双臂 + 四模块（分工定型，问题转移）

修补思路：既然配药动作可以分解为四类（抓取 / 抽吸注射 / 消毒开启 / 安置），就让四个模块各管各的自由度，抓取用笛卡尔坐标操作臂在竖直平面内运动——移动关节解耦、结构刚度高、没有运动学奇异点，控制退化成两根丝杠的联动【可查证：§3.3 动机原句】。

v1 内部要做的决定，按当时的顺序：

- **传动链**：直线运动用滚珠丝杠 + 滚珠导轨（摩擦小、无侧隙、刚性高，定位能到微米级）；旋转用行星齿轮减速箱（刚性好、精度高、效率高）；转动架用同步带（准确、平稳、高效）【可查证：§3.2】。大负载竖直轴不设减速器以提高效率（自由度 5 选 750W 三菱 HF-KP75B 直接连丝杠）【可查证：§3.3】。
- **自由度分配**：抽吸注射 4 个（旋转、拉压、夹筒体、夹活塞杆），抓取 4 个（竖直、水平、手爪旋转、夹持），消毒开启 3 个（转动架、瓶颈力矩、刀轮直驱），药品安置 1 个（药架旋转）——合计 12 个【此处是 v1 收口时的盘点，事后与论文表 2-1 一致；正文其余段落不引用这一事实】。
- **西林瓶的负压问题**：抽取西林瓶药液时瓶内形成负压，抽取阻力随液面下降增大【可查证：§3.4】。我们的应对是改变针头姿态与抽取路径，具体方案在两个瓶型上分开设计（图纸上安瓿、西林各一套抽液姿态）。

v1 暴露的三个新问题，每一个都比 v0 的更具体：

1. **回零干涉**。两个机械臂在同一个工作空间里，用回零开关逐轴回零，动作序列稍有不慎就互相砸。这是 v1 最接近"杀死项目"的问题——硬件都装好了才发现两臂的回零路径是交叉的。
2. **消毒怎么做**。人工流程是镊子夹消毒棉擦拭，等待 1 分钟再操作【可查证：§3.5.1】。如果让机器模拟"擦拭"，需要镊子 + 棉花补给 + 换棉逻辑，机械结构会复杂到不可接受【可查证：§3.5.1 原话"如果采用机械装置来实现，需要的机械结构将会十分复杂"】。
3. **安瓿瓶开启**。依然是空白。划割、掰折两个动作要在一个机构里完成，而且要适配不同规格。

## v2：三个补丁 + 一个总架构

**补丁一（消毒）：喷射替代擦拭。** 市场调研发现喷射消毒器是成熟商品，喷射消毒不接触物体、自适应性强，正好命中"不同规格药瓶"的需求。系统定为：消毒液瓶 + 微型隔膜泵（泵机分离防油污污染）+ 雾化喷嘴 + 继电器控制【可查证：§3.5.1 图3-6】。喷嘴选压力雾化式，用伯努利方程推出出口流速与进口压力的关系 v = 44.7√p（p 单位为 MPa、水介质）【可查证：式(3-1)~(3-3)】。这里有个隐藏的指标属性问题：**雾化不是越大越好**——喷射过密、颗粒过大，消毒液会粘附在瓶身形成液滴，反而造成二次污染【可查证：§3.5.1】。这是本项目第一个"有可用窗口"型指标。

**补丁二（开启）：划割 + 掰折一体化。** 方案：转动架上装划割电机与合金刀轮，环形划割瓶颈；开启器另一侧做楔形槽，卡住瓶帽后由机械手夹持瓶身转动掰折【可查证：§3.5.2 图3-11】。楔形槽顺带能开西林瓶（顶住塑盖圆弧边缘，机械手相对运动拨出）——一个机构管两种瓶，这是 v2 里最省成本的一步。开启器材料选 S136 模具钢（耐磨、防腐、尺寸稳定），两种工况做静力分析验强度【可查证：§3.5.2(3)】。

**补丁三（回零）：绝对位置控制。** 放弃回零开关，用三菱 MR-J3-A 的绝对位置控制：上电后按协议时序读 ABS 数据（19 个数据包、38 位：32 位电机位置 + 6 位校验），拿到各关节当前位置后按安全的先后顺序逐轴归零【可查证：§5.3.1】。时序错了伺服报 AL-E5，所以要写精确延时函数。

**总架构**：PCI 集中式控制，工控机 + 两片六轴运动控制卡 + 数据采集卡 + 力传感器 + 工业相机 + 平行背光光源【可查证：第 5 章硬件清单】。
