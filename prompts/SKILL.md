# 论文科研全仿真（paper-research-simulation）

把一篇已发表论文"逆向还原"为第一人称的研究全过程叙事。核心增量不在复述论文，而在还原论文里被删掉的 80%：naive 想法怎么死、建模怎么从弱迭代到强、实验怎么崩又怎么救。

## 最高纪律（违反任何一条，当前阶段输出作废重来）

1. **无后见之明**：每个阶段开头必须声明"你不知道这篇论文最终成功了"。只许用该阶段时间点之前可得的信息叙述。
2. **来源标注义务**：每个实质性判断必须打标签——`【可查证】`（注明论文章节/图表/公开资料）或 `【合理重构】`（注明推断依据）。不允许无标签断言。
3. **负结果占比 ≥40%**：被毙掉的分支、失败的实验、走不通的方向，篇幅不得低于 40%。论文是幸存者偏差，仿真必须纠偏。
4. **阶段隔离**：一个会话轮只跑一个阶段。上一阶段的《档案》是下一阶段的唯一剧情输入。禁止一次性生成全文。
5. **口径三段式**：每次启动阶段，用户（或主控 AI）用三句话交代——我们的目标 / 我们的现状（=上一阶段档案）/ 我们的限制。
6. **缺席断言禁令**（第四轮起生效，2026-09-17）：任何"论文从未／均未／没有／未提及 X"的断言，须先全文检索并在《档案》里注明检索词与命中条数；答不出检索记录的，改写为"我在 X 范围内没有找到"。前三轮唯一的 P0 三次都是这一形态（把"不在我的注意范围里"写成"不在论文里"）。

## 运行管线

```
S0 选材闸（防御性检查，不过则终止并说明理由）
  → S1 idea 诞生
  → S1.5 内部博弈（多作者分歧：一作/导师/合作者三角拉扯）
  → S2 文献调研
  → S3 建模迭代（v0→v1→v2，必须写出中间版本）
  → S4 数据 + 实验（双轨；大模型论文数据轨为主战场）
  → S5 困难与转折（负结果深挖）
  → S6 成文
  → S7 审稿 + rebuttal（审稿人必须开全新会话，只喂论文，不喂档案）
  → S8 对照复盘（幻觉总检查：故事曲线 vs 论文真实图表；**第 -1 步图轨必跑**，变体 A 跑降级版）
  → S9 成稿（可选：把 S1–S8 融合成一篇面向外行读者的连续第一人称长文，附迷你复检）
```

**MVP 路径（首次使用只跑这 5 个）**：S0 → S1 → S3 → S4 → S5 → S8。S1.5/S2/S6/S7 为扩展阶段，第二轮再加。多作者论文（≥3 个单位或作者背景差异大）建议把 S1.5 提前到第一轮。

**判形态（第三轮起，第六轮扩为三型）**：先判这篇论文属于哪一型——
**变体 A（纯文本 / 表格驱动，实验对比型）**：核验物是数值表格，S8 第 0 步跑"逐行算差值"；
**变体 B（图像密集型湿实验）**：主图 ≥5 张、补充材料含多条 Note/Table/Fig、有器件表征或人体／动物实验环节，S8 第 0 步改跑"逐图逐行重算 + 图注-正文-图面三方对齐"；**另加一条判据：验证链是否存在**——设计报告型论文的摘要 claim 与验证数字之间可能完全断层（配药机器人轮实测：摘要"可完全取代人工操作"与正文"试运行不足"之间没有任何数字），缺验证链时 S0 需降级放行并把"验证层为空"写成随行风险；
**变体 C（趋势拟合型／标度律型）**：核验物是**拟合参数与概括句**，论文没有"可逐行做差值的对比表"（Scaling Laws 轮实测：S8 第 0 步的"逐行做差值"在这一型上**无空间**）——S8 第 0 步改跑"**措辞与数值的量级匹配 + 跨章节同一参数的一致性**"（该轮靠它抓到 Abstract "more than seven orders" 与 §1.1 "more than six" 的矛盾、§4.2 "differ very slightly" 而实际差 67%、同一参数 Nc 在 §3 与 §4 两张表里不同）。
变体 B 的五处替换见 references/stage-prompts.md 的「变体 B」一节；变体 C 的四处替换见同文件「变体 C」一节。

## 图轨（变体 B 的核心增量，与《档案》平行）

**核验物是图而不是表格的论文，必须真的去读图。** 图轨是 S4 与 S8 的共享输入：只回答"从图上能直接读出什么"，不做因果推断、不评价方法好坏。

三条纪律：① 只报可直读的量（轴范围、刻度、平台高、柱高、条数、端点、是否顶到上限）；② 每个读数带**图号 + 面板号**，目视或像素分割得来的必须写"约"；③ **读不出的必须写"读不出"或"缺件"，不许用正文补位。**

工具四步（脚本见 `scripts/`）：抽内嵌栅格 + 整页渲染 → 逐面板裁剪（**含纵轴标签带**）→ 找框线 → 曲线数字化。**标定优先找图内自带的标定点**（本轮用"图注给出 5 个时间戳 + 图里有 5 条竖虚线"反解像素-秒比例，自带残差检验）。

**第五轮（配药机器人轮）新增两条**：①**内嵌位图可能整体上下颠倒存储**（fitz 抽出的 PNG 颠倒、整页渲染正常）——读位图前先垂直翻转，或改读整页渲染，否则文字与坐标全读反；②**有数值色标的图（有限元云图等）必须做"正文数字 vs 色标刻度"对账**——本轮靠它抓到 P0：正文把色标中间刻度（27.94）当最大应力，色标顶格实为 83.82（恰 3 倍整）。

三个实测结论（第三轮）：
1. **图轨能撤销假发现**，而且撤销过两次——一次撤掉流程自己的先验猜测，一次撤掉隔离审稿人的指控。**因此图轨必须与叙事和审稿输出同权。**
2. **凡论文里同时出现"两个都合理但不同的数字"，先去找有没有一张图能直接算出其中一个。** 能算出 → 口径问题；算不出 → 才升级为矛盾。（第三轮靠这一步把一条候选 P0 降成 P2。）
3. **图注是最接近图面的文本锚点**：正文可以隔着缺件引用，图注不能。三方不一致时先看图注站在哪边，能立刻分开"正文口径问题"与"图面/数据问题"。

S8 由三节扩为**四节**：新增**【不可核验清单】**（依赖拿不到的图/表/Note/影片）与**【假发现撤销清单】**。

**档案流转**：每阶段输出 = 叙事正文 + 末尾固定格式的《档案》块（契约见 references/stage-prompts.md 第 0 节）。档案是阶段间唯一接口，字段缺失视为接口违约，补齐后才允许进入下一阶段。**第四轮起《档案》新增两个必填字段：【措辞自检】与【缺席断言检索】。**

## S0 选材闸（防御性检查）

输入论文后先过闸，逐条检查，任一不满足则拒绝并给出替代建议：

- 单方法论文（非综述、非 benchmark、非大系统报告）
- 有明确的核心 claim 和可定位的主实验（主实验数 ≤5 为佳）
- 有开源代码或足够的方法细节，使"建模迭代"阶段有据可依
- 用户具备该领域的前置知识（缺前置先补，仿真不是替代学习）

**推荐处女作**（RL 方向，均已验证适配）：首选 **PPO**（Schulman et al. 2017, arXiv:1707.06347；CleanRL 有 340 行单文件实现 + "37 个实现细节"博客可作 S8 对照材料）；备选 **TD3**（Fujimoto et al. 2018，官方开源，主实验少）、**DQN**（Mnih et al. 2015 Nature，经典但实验偏多，适合第二轮）。

## 使用方式

1. 用户给出论文（PDF / arXiv 链接 / 标题均可，优先拿到全文）。
2. 跑 S0。过闸后，打开 references/stage-prompts.md，取当前阶段模板，填入材料，独立会话执行。
3. 用户审阅该阶段输出 → 确认或打回 → 进入下一阶段。
4. S8 收尾后，强烈建议用户用同一篇论文跑一次真实主实验复现，对照差距（仿真的局限：给不了调代码的肌肉直觉和现实耳光）。

## S8 收尾：合订 PDF（scripts/ 已捆绑，2026-09-15 GPT-1 首跑沉淀）

S8 通过后把 S1–S8 合成一份可交付的 A4 文档。三条命令：

```powershell
$py = "C:\Users\A\.workbuddy\binaries\python\envs\default\Scripts\python.exe"
& $py scripts\build_stage_pdf.py  --dir <论文目录> --out "<论文>_完整版.pdf" `
     --title "GPT-1 科研全仿真" --subtitle "<论文全名（作者, 年 · 形态）>" `
     --meta "<体例 + 来源 + 修订注说明，可含 <br>>" --preview-dpi 70 --log <log>
& $py scripts\build_stage_html.py --dir <论文目录> --out "<论文>_完整版.html" --title ... --meta ...
& $py scripts\qc_pdf.py "<论文>_完整版.pdf" --out <qc.txt> --dpi 70 --preview <预览目录>   # 必跑
```

交付物三件：**PDF（主交付，present_files 排第一）+ 同名 HTML（离线可看）+ S*.md 源稿**。

**本机三个坑（GPT-1 实测，别再踩）**

1. **Edge/Chrome 无头打印在本机会静默失败**：`& msedge.exe --headless=new --print-to-pdf=...` 返回空 stdout、无退出码、不产文件（沙箱内外一致，`Start-Process` 也被拦）。→ 改走 **`fitz.Story`**（PyMuPDF 1.28 自带 HTML/CSS 分页引擎），全 Python 闭环，`build_stage_pdf.py` 已实现。中文字形直接由 `font-family: sans-serif` 落到内置 CJK 字体，不必外挂 ttc；副作用是每个 PDF 约 3.6–4.8 MB（字体整包嵌入）。
2. **别拿 notes-to-review-pdf 的 `build_review.py` 直接打这类文档**：它的数学占位符保护用 `\$.*?\$` 配对，会把正文里的**字面 `$`**（如分隔符记号 `premise $ hypothesis`、`[z; q; $; ak]`）跨段配对，被"保护"的整段绕过 Markdown 解析、以原文形态落进 HTML。本类文档没有 LaTeX，跳过保护即可（`build_stage_*.py` 已跳过）。
3. **`os.replace` 覆盖既有 PDF 被沙箱拒（WinError 5）** → 加页码改用 `doc.save(path, incremental=True, encryption=fitz.PDF_ENCRYPT_KEEP)` 写回同一路径。

**fenced code 围栏里不许写 Markdown 语法**：《档案》块是 ``` 围栏，`**加粗**`／`~~删除线~~`／反引号写在里面会**原样印出**。GPT-1 首跑踩了 6 处（修订注被误写进围栏 → PDF 里出现字面 `> **`）。规则：**修订注一律放围栏外**，围栏内只用 `【标签】` 纯文本。`qc_pdf.py` 的残留检查（`**` / ``` / `QQMATH`）就是查这个 —— 必须全 0 才算过。

**第 4 个坑（GPT-2 轮补）**：正文／表格里的**作者星号标记**（`Radford\*、Amodei\*\*`）会被渲染成字面 `**`，同样卡住残留检查（GPT-2 轮踩在 S0 的作者表与 S1.5 的行内反引号里）。→ **用文字描述代替星号**（"以星号标注前两位与末两位共四人同为同等贡献"）。行内反引号包住的 `**` 也照样落成字面 `**`。

## S9 收尾：篇幅自检 + 迷你 S8（scripts/ 已捆绑，2026-09-15 GPT-2 轮沉淀）

```powershell
& $py scripts\s9_selfcheck.py --s9 <成稿.md> --stages-dir <论文目录> `
     --key-numbers "<上一轮 S4 第 9 节的硬数字，逗号分隔>" `
     --p0-fingerprints "<上一轮 S8 幻觉清单里 P0/P1 条目的原句关键词>" --out <报告.txt>
```

⚠️ **换论文必须传 `--key-numbers` 与 `--p0-fingerprints`**：脚本内置的是 GPT-1 首跑的清单，不传就会拿着另一篇论文的数字去查这一篇。

篇幅口径的三个数字指的是**同一篇文章**，别混：含 S8 分母 = 67.0%、漏 S8 = 84.3%、按字符数 = 40.2%（GPT-2 轮实测）。判定一律用第一个。

**篇幅下限的豁免条款（第五轮起生效，2026-09-15）**：第 5 条的 60–70% 是**产品规格**，不是硬门槛。实测四篇连续低于下限（GPT-1 61.7% 达标；GPT-2 67.0% 达标；Transformer 36.5%、配药机器人 27.0%、Scaling Laws 37.8% 均低于下限），原因是**阶段叙事（尤其 S8）比成稿长得快**——S8 是审计报告，天然比面向读者的叙事长。故：
- **豁免条件**：成稿满足「负结果占比 ≥40%」**且**「S4/S8 硬数字覆盖完整」两项补判据时，篇幅比低于 60% 不判不合格，但必须在《档案 · S9》里记两个比值（实际比 / 下限）与豁免理由；
- **两项补判据的核算**：负结果占比沿用 S5/S9 人工核算；硬数字覆盖用 `scripts/s9_selfcheck.py` 的关键数字命中报告；
- 反过来说：**豁免不等于放松**——成稿若同时低于 60% 且负结果占比不足，仍判不合格。

外行闸的抽检与记录口径、以及"成稿不得引入阶段叙事里没有的材料"这条素材边界，见 references/stage-prompts.md 的 S9 第 6、7 条。
