# 阶段提示词模板与档案契约

## 第 0 节：档案契约（阶段间唯一接口）

每阶段输出的末尾必须附带如下《档案》块，字段缺一不可：

```
《档案 · S{n}》
【阶段】S{n} {阶段名}
【已知事实】（仅列【可查证】条目，每条注明出处：章节/图/表/公开资料链接）
【合理重构】（推断条目 + 一句推断依据）
【负结果】（本阶段被毙掉的方向及死因；累计占比须向 40% 靠拢）
【标注覆盖率】本阶段实质性断言共 N 条，其中标【可查证】x 条、【合理重构】y 条（x+y 必须等于 N；生成时自查，S8 复核）
【未决问题】（留给后续阶段的钩子；没有就写"无"，不许编）
【一致性自检】一句话：本阶段推出的判断，是否与上一阶段《档案》的任一【已知事实】冲突？（是→先解决冲突再交档；GPT-1 首跑中 S1"全文未提 GLUE"与 S2"论文引用了 GLUE"直接对撞，无人发现，存活到 S8）
【后见之明自检】一句话：本阶段是否泄露了论文最终结果？（是→作废重来）
```

纪律条款放在每份模板的开头和结尾（长文本首尾注意力最强），材料夹中间。

**关于"无后见之明"的诚实注记**：LLM 训练语料很可能包含目标论文及其解读，"你不知道结局"的声明是弱约束——它能约束语气，约束不了知识。真正的硬约束是 S8 核查：叙事里任何"恰好猜中"的直觉都视为可疑，须能给出当时可得的依据链，否则按后见之明泄露处理。

## S1 · idea 诞生

```
角色：你是这篇论文的第一作者，时间是 idea 诞生前一周。
纪律（违反即作废）：你不知道这篇论文最终成功了；你不知道最终方法长什么样；
禁止以后见之明说话；每个判断打【可查证】或【合理重构】标签。

我们的目标：还原这个问题的 idea 是怎么诞生的。
我们的现状：[粘贴论文 abstract + introduction + 你过 S0 时确认的论文基本信息]
我们的限制：只能用该论文发表日之前公开的材料作为"当时的知识背景"。

输出（1200 字左右，第一人称，口语化）：
1. 我当时在做什么、怎么注意到这个问题的（哪个具体现象/哪句话刺到了我）
2. 我的第一个 naive 想法是什么——必须写出来
3. 它卡在哪、为什么死（这是负结果，写透）
4. 哪个词、哪篇文献、哪次讨论给了我转机

末尾附《档案 · S1》。
再强调一次：你是"当时的你"，不是读过论文的你。
```

## S1.5 · 内部博弈（多作者分歧，扩展阶段）

真实多作者论文不是一个人的独白：一作想冲、导师让稳、合作者砍 scope。
本阶段模拟作者间的拉扯，让"思路为什么长这样"多一层人的因素。

```
角色：你是这篇论文的全部作者，分饰三角——
  一作（想做出东西、愿意冒险）、导师/资深作者（求稳、管故事线和投稿策略）、
  合作者（管资源、负责砍 scope）。
纪律（违反即作废）：时间点同 S1，无人知道论文最终成功；
每个立场必须有利益动机，不许为了吵架而吵架；每个判断打【可查证】或【合理重构】。
（作者数、资历结构可从论文作者列表和单位【合理重构】。）

我们的目标：还原 idea 在团队内部被质疑、修正、定型前的博弈。
我们的现状：[《档案 · S1》+ 论文作者列表与致谢]
我们的限制：只用发表日之前的信息。

输出（1000 字左右）：
1. 三次真实分歧：各是谁和谁、争什么、各自动机（如"做 zero-shot 还是继续刷微调榜单"
   "数据用 Common Crawl 还是自己爬""1.5B 要不要放出来"）
2. 每次分歧怎么收口的：谁妥协、用什么证据说服、还是投票
3. 被砍掉的 scope：有哪些想法死了不是因为它错，是因为没人手/没算力/怕风险【负结果】
末尾附《档案 · S1.5》。
再强调一次：这是发表前的团队，不是庆功宴上的团队。
```

## S2 · 文献调研（扩展阶段）

```
角色：同上，时间是 idea 确立后、动手建模前。
纪律：同 S1。
目标：还原"我站在哪"——这个问题的前人工作地图。
现状：[《档案 · S1》+ 论文 related work 全文]
限制：只许引用发表日之前的文献；related work 里没提但【可查证】当时已存在的关键工作，可以补，但必须注明"论文未引"。

输出：
1. 这个问题的前人路线分几派，各派代表作和死穴（每条打标签）
2. 我和哪一派是亲生的、和哪一派划清界限、为什么
3. 至少一处"我以为没人做过、查到发现有人做过"的惊魂时刻【合理重构】
末尾附《档案 · S2》。
```

## S3 · 建模迭代（核心，不许跳过中间版本）

```
角色：同上，时间是动手建模期。
纪律：同 S1。禁止直接跳到论文最终形式。
目标：还原方法从弱到强的迭代链。
现状：[《档案 · S1》(+S2) + 论文 method 章节]
限制：v0/v1 可以是【合理重构】，但每一版的"死因"必须说得让内行信服。

输出：
1. v0：最直接的形式化。写出来，然后写它为什么不够（理论缺陷 or 实验预期缺陷）
2. v1：修补后的版本。修补思路从哪来，又暴露了什么新问题
3. v2：逼近论文最终形态的版本。最后一块拼图是什么
4. 对照论文最终方法：我的迭代链和它的距离（这段允许看论文，其余段落不许）
纪律补充（GPT-1 首跑教训）：**凡陈述"某个设计是为了解决某个问题"，必须引出论文里的动机原句**，否则降级为待验猜想。S3 曾把 v1 的 aux LM 动机写成"治小数据过拟合"，而论文 §3.2 的原句是 "improving generalization ... and accelerating convergence"，Table 5 更显示 aux 在小数据上是负贡献——动机错了，整条迭代链就救错了人。
末尾附《档案 · S3》，其中【负结果】必须包含 v0、v1 的死因。
```

## S4 · 数据 + 实验（双轨，核心）

数据轨和实验轨分开写。对 RL 论文，数据轨可压缩为一段；对大模型训练论文，
数据轨是主战场（如 GPT-2 的 WebText 构建与清洗），篇幅不低于实验轨。

```
角色：同上，时间是方法定型、开始准备数据和跑实验。
纪律：同 S1。实验叙事里的曲线走向不许照抄论文结论（那属于 S8 的对照材料）。
目标：还原"数据从哪来、为什么这么测"背后的博弈。
现状：[《档案 · S3》+ 论文 experiments / dataset 章节]
限制：承认算力/时间限制（用论文时代的主流配置推断）。

输出：
【数据轨】
1. 数据从哪来：自建还是公开？当时有哪些候选数据源，各自被谁否决、为什么
2. 清洗与筛选：定过什么规则？有没有"定完规则发现把好东西也滤掉了"的返工【负结果】
3. 数据规模怎么定的：是算出来的、试出来的、还是"只有这么多"
【实验轨】
4. 我要回答的核心问题是什么 → 倒推出需要哪几个实验
5. baseline 选谁、为什么；最怕被谁比下去
6. 超参数怎么定的（坦白哪些是抄惯例、哪些是调出来的）
7. 消融实验：每个被拆掉的组件，是在回应哪个质疑
8. 至少一次"实验崩了"：现象、排查路径、根因【合理重构】（负结果重点区）
纪律补充（GPT-1 首跑教训）：**凡是"某组件救了我"的归因，必须与该组件在论文消融表里的逐任务差值对齐**（同一条归因，方括号依据与正文各说一半、句内自相矛盾，是本阶段最高频的失误形态）。另：论文若报了正面硬数字（总均分、perplexity、层迁移增益等），本阶段至少要吸收一次——GPT-1 首跑把 GLUE 72.8 vs 68.9 整段漏掉了。
末尾附《档案 · S4》。
```

## S5 · 困难与转折（负结果总账）

```
角色：同上，时间是项目最黑暗的时期。
纪律：同 S1。本阶段负结果是主角，不是点缀。
目标：把前几个阶段埋的失败集中引爆——这个项目离死掉最近的一次。
现状：[《档案 · S1..S4》]
限制：不许编造论文结果层面的失败（论文确实成功了）；
只能写过程中真实的挫败类型：方向误判、实现 bug、理论证不出、审稿人预判等。

输出：
1. 至暗时刻：具体是什么、持续了多久、我当时怎么判断"该救还是该弃"
2. 救回来的转折点：是换了视角、换了工具、还是认怂砍了 scope
3. 复盘：这个坑能不能在 S1 就避开？（诚实回答：大多数不能，这就是研究的性质）
末尾附《档案 · S5》，并更新全局负结果占比统计（须 ≥40%）。
```

## S6 · 成文（扩展阶段）

```
角色：同上，时间是写论文。
目标：还原叙事策略——同一堆材料，怎么讲才卖得出去。
现状：[《档案 · S1..S5》+ 论文全文]
输出：
1. 标题和 abstract 的取舍：放大了什么、藏起了什么
2. 哪个结果放主图、哪个塞进 appendix、为什么
3. related work 里的外交辞令：哪句话是在 preempt 审稿人
末尾附《档案 · S6》。
```

## S7 · 审稿 + rebuttal（必须独立会话）

> 实现备忘（2026-09-15 GPT-1 首跑验证）：会话 A 的"全新会话"可用 **Agent 子代理**等价实现——子代理天然无主线记忆，提示词里只给论文文件路径和审稿人设定，绝不粘贴任何《档案》。不必要求用户手动开会话。注意子代理输出有作者滤镜归零的效果：它可能独立发现主线叙事淡化的矛盾（如消融表内部不一致），这类发现要记入档案并作为 S8 重点核查项。

会话 A（审稿人，全新会话，只喂论文全文，不喂任何档案）：
```
你是一位以严苛著称的审稿人，领域对口。这篇论文投到了你的桌上。
给出 3 条 major weakness，每条要具体（引用章节/图表），不接受"实验不够多"这种空话。
按真实审稿口吻输出 review。
```
会话 B（作者，回到主线会话）：
```
角色：第一作者，刚收到审稿意见。[粘贴审稿人输出 + 论文相关章节]
写 rebuttal：哪些认怂修改、哪些据理力争、哪些用新实验回应。
策略要符合该会议/期刊的真实博弈规则。
末尾附《档案 · S7》。
```

## S8 · 对照复盘（幻觉总检查，必跑）

```
角色：你现在是第三方核查员，不再是作者。
任务：把前 7 个阶段的叙事和论文真实结果逐项对照。
输入：[全部《档案》+ 论文全文]

第 0 步（GPT-1 首跑证明最有效的一步）：**先重算论文自己的趋势表，再读叙事**。
挑出论文里所有"概括句"（如 "larger datasets benefit ... but smaller datasets do not"），把支撑它的表逐行做差值，
看有没有反例。GPT-1 首跑正是靠这一步抓出 RTE：它是全场最小数据集，却因 aux LM 涨了 1.6 分，
论文的两句概括在它身上互相打架。这一步必须在读 S1–S7 之前做，否则会被自己的叙事锚定。

输出三张表：
1. 【对上了】叙事与论文一致的点（这是材料扎实性的证明）
2. 【编圆了但论文没这回事】幻觉清单：逐条列出，标注出自哪个阶段与严重度（P0 与论文事实直接矛盾 /
   P1 因果夸大或论据错位 / P2 标签错配与表述不严）——这是本仿真系统的误差报告，也是下一轮调模板的依据
3. 【论文有而叙事漏了】覆盖度缺口（单列一节：论文正面的硬数字是否被叙事吸收）
另外单设一节核 S7：审稿人三条 weakness 的数字逐条复验、rebuttal 引文逐条复验、隔离是否真合规。
最后回答一个问题：这套仿真教会我的东西里，哪些是读论文原文绝对学不到的？（须分层并声明哪些是史实、哪些只是重构）
末尾附《档案 · S8》。
```

## S9 · 成稿（融合长文，面向"只懂皮毛"读者的第一视角文）

S1–S8 是带标签和档案块的工作稿，直接拼接不可读。S9 把它们融合成一篇连续的第一人称长文。
目标读者：只知道一点皮毛的人，读一遍就能懂核心理论。

```
角色：你是第一作者，项目结束一年后，给非本领域的聪明朋友讲这段经历。
输入：[S1–S8 全部档案（事实骨架）+ 各阶段叙事正文（素材）]

改写规则（六条，逐条可验）：
1. 视角统一：全部回到第一作者第一人称。S7 审稿段改写为"收到意见那两周"的作者视角；
   S8 的三张表不进正文，压缩成文末附录《勘误与对照》保留——诚实性不许丢。
2. 标签转写：行内的【可查证】/【合理重构】撤掉，改用语气承载（"我记得""我当时猜"），
   但每个重构点必须在章末注留痕（一条一行：哪个判断、依据是什么）——可核验性不许丢。
3. 理论三层讲法：核心理论首次出现时按"一句直觉类比 → 一段机制 → 可选公式/伪代码"给；
   每个类比后面必须补一句"它哪里不像"，防止类比带歪理解。
4. 结构重排：不按 S1–S8 时间线，按"问题 → 直觉 → 试错 → 定型 → 验证 → 反思"的故事弧排；
   每章开头放一句本章论点。负结果占比仍须 ≥40%——好读不等于把失败删了。
   ⚠️ 幕数不固定（GPT-2 轮实测补入）：五幕的最小形态是
   "问题 → 直觉 → 试错 → 定型与打脸 → 反思"；当 S6（成文）的取舍密度足够高时，
   可把它单列一幕"讲法"插在"定型"与"反思"之间（那篇实测为六幕）。
   **判据不是好不好看，是"讲法"那一幕有没有独立论点**——GPT-2 的独立论点是
   "能改的只有说法，而每一个说法上的决定都是防守"；给不出这样一句，就不要单列。
5. 删重：合并后总篇幅为各阶段之和的 60–70%，重复的背景交代只留第一次。
   ⚠️ 口径（S9 首跑实测补入）：**分母按各阶段叙事正文的"汉字数"计，且必须含 S8**（S8 本身就是一份长审计报告，
   漏掉它会把 61.7% 算成 99.1%，结论完全相反）；按字符数（含标点西文）算同一稿件只有 37.6%，两个口径差 24 个百分点。
   与任务书里的字数规格（如"6000–9000 字"）冲突时，以字数规格为准，并把差额记进《档案 · S9》。核算脚本：
   `scripts/s9_selfcheck.py --s9 <成稿.md> --stages-dir <论文目录> --key-numbers <上一轮 S4 第 9 节的硬数字清单>
   --p0-fingerprints <上一轮 S8 幻觉清单里 P0/P1 条目的原句关键词>`。
   ⚠️ **换论文必须传这两个参数**（GPT-2 轮实测补入）：脚本内置的是 GPT-1 首跑的清单，不传就会拿着
   另一篇论文的数字去查这一篇，结论驴唇不对马嘴。字体口径陷阱在 GPT-2 轮再次复现：同一稿件含 S8 算 67.0%、
   漏 S8 算 84.3%、按字符数算 40.2%——**三个数字指的是同一篇文章**。
6. 外行闸：写完随机抽三段，让一个扮演外行的 AI 回答"这段讲了什么"，答错则重写该段。
   ⚠️ 判定与记录口径（GPT-2 轮实测补入）：
   - 抽检三段要覆盖**不同类型的难点**，不要三段都抽叙述段。GPT-2 轮抽的是
     "数值比较段（LAMBADA 的两个数）+ 类比机制段（字节级 BPE）+ 取舍清单段（摘要放大/藏起）"。
   - 每段除了复述，再出**两道理解题**（考因果，不考记忆）。"能复述"远弱于"能答对因果题"。
   - **必须向被抽检者说明：答错说明写作者写得不够外行友好，请如实说"没看懂"，不要编一个听起来合理的答案。**
     这句话不写，子代理会礼貌地顺着你说懂——闸门就废了。
   - **记录必须包含被抽检者列出的"只能靠上下文猜的词表"**，而不仅是通过/不通过。
     GPT-2 轮是 3/3 通过，但外行仍列出一长串术语（LAMBADA、停用词、权重、码点、困惑度、F1、BLEU…）——
     **"通过"不等于"术语不构成门槛"**，两件事要分开记。
   - 补释义也有边界：给**首现的通用术语**补一句话括号释义；基准/数据集专名（CoQA、Winograd、1BW）
     与"对数线性"这类只在语境里起修饰作用的词不补——给每个专有名词都加释义会把文章变成词典。
7. 素材边界：**成稿只许改写 S1–S8 里已有的内容，不得引入阶段叙事里没有的材料。**
   确需补（例如某个能显著提升可读性的论文事实在阶段叙事里被漏掉了）时，必须在附录《勘误与对照》里
   单列一条并注明"阶段叙事未吸收、成稿跨阶段取材"，同时在《档案 · S9》的【未决问题】里写下
   "下一轮应改为先把缺口补进 S4/S8，再写 S9"。**默认做法是别补，把缺口留在覆盖度清单里。**

最后必跑【迷你 S8】：改写会引入新幻觉——对照 S8 的幻觉清单和论文硬事实清单，
逐条确认 P0 错误没有在成稿里复活，并检查新文本自身有无新增无依据断言。
机器可判的部分由 `scripts/s9_selfcheck.py` 出（P0 指纹命中 + 硬数字覆盖），**语义级新断言仍须人工/子代理过一遍**：
GPT-2 轮的做法是把成稿里**每一个新写进去的数字**回原文逐条核到原样出处（例如 30% 零重叠与 2.6% 中位数、
273/10/2/1、8.6→8.7 与 63.2%→62.9%、10MB 法语、26 次 `<UNK>`），核不出来的删掉。
输出：成稿全文（含章末注 + 附录《勘误与对照》+ 外行闸记录）+ 《档案 · S9》（只记改写决策与新增风险）。
⚠️ **《档案》的代码围栏里不许写 Markdown 语法**（`**加粗**`、`~~删除线~~`、反引号会原样印进 PDF）；
修订注一律放围栏外。同理，正文表格里的作者星号标记（`\*\*`）也会被原样渲染成 `**` 而卡住 qc 残留检查——
**用文字描述代替星号**。构建后必跑 `scripts/qc_pdf.py`，残留（`**` / ``` / `QQMATH`）必须全 0。
```
